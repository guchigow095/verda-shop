# Verda - Интернет-магазин фермерских продуктов

Учебный SPA-проект (создан в рамках обучения с ментором), представляющий собой интернет-магазин с каталогом товаров и интерактивной корзиной.

## Стек технологий
- React, TypeScript
- SCSS, BEM, Flexbox
- Redux (управление состоянием корзины)

## Функционал
- Адаптивная верстка по макету.
- Слайдер на главном баннере.
- Динамическое изменение количества товаров (плюс/минус).
- Блокировка кнопок при отсутствии товара.
